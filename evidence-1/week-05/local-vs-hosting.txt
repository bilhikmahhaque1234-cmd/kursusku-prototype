Aspek         | Local Development (Kondisi Proyek Saya) | Hosting / Production (Yang Seharusnya)

Lokasi File   | Laptop mahasiswa                      | Server hosting
Database      | MySQL lokal Laragon (jika digunakan)  | Database server hosting
Environment   | Development                           | Production
HTTPS/SSL     | Tidak selalu tersedia                 | Seharusnya HTTPS aktif
Debug         | Boleh membantu proses belajar         | Jangan menampilkan detail error sensitif
Secret        | Disimpan lokal, tidak dibagikan        | Disimpan aman sebagai konfigurasi server
Document root | Folder proyek di Laragon              | Folder web yang ditentukan provider hosting

Refleksi singkat (jawab dengan kata-kata sendiri):
1. Apa risiko jika prototype ini langsung diunggah ke hosting publik tanpa HTTPS?
Data inputan form (seperti nama, email, hp) dikirim tanpa enkripsi sehingga rawan diintip atau dicegat oleh pihak ketiga di jaringan (serangan Man-in-the-Middle).

2. Bagian mana dari kode Anda (jika ada) yang masih menulis path lokal atau informasi yang tidak boleh dibagikan ke publik?
Penggunaan path include/require yang masih bersifat lokal serta konfigurasi kredensial bawaan lingkungan pengembangan lokal.

3. Apa perbedaan utama cara menangani error di local vs production menurut Anda?
Di lingkungan local, pesan error ditampilkan secara detail untuk mempermudah proses debugging. Sedangkan di production, detail error harus disembunyikan dan diganti dengan halaman peringatan ramah pengguna agar kredensial atau struktur sistem tidak bocor.
